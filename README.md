### 3. **결정된 사항 (2025-08-22 정책회의)**

- 비회원도 OX게임 **공통상식** 풀이 가능
- 회원가입 → 쿠폰 지급
- "마일리지(러닝포인트)" 통화 도입
- 적립 7가지: 게시글 / 퀴즈풀기 / 이벤트참여 / 출석 1마일/회 / 질문권(큐챗) / 완강 / 수강후기
- 사용 5가지: 기프티콘 자판기 / **OX해설 교환권** / 할인쿠폰 / **OX상점(꾸미기)** / 뽑기
- 소멸: 적립 후 1년
- OTP 인증 / 기기제한 없음(로그 모니터링) / 무료연장은 쿠폰

### 4. **추후 논의 미해결 (정책회의 명시)**

- 실시간정책
- 캐시사용 여부
- **게임 관련 정책** ← OX게임 등급분류 포함
- 인앱결제 관련
