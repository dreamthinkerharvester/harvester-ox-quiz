## 4. v3 PRD 후보 — ROI 우선순위

### 🥇 P1. Grand Slam 시스템 (가장 강한 ROI)
- **트리거**: 11라운드 (조정 가능) 모두 정답 시 종료 화면 분기 추가
- **연출**: 별도 트로피 + 코인 비 + Grand Slam 전용 공유 문구
- **동기**: 영상에서 시청자 환호 = 재플레이 강한 트리거
- **추정 코드**: ~30 LOC (state.allCorrect 추적 + renderEnd 4분기 확장)

### 🥈 P2. 카테고리/레벨 시스템
- **메뉴**: 메인 화면에 `Lv.X / N/M 게이지` + 카테고리 ("일반상식" / "스포츠" / "역사" 등)
- **동기**: 200문항 한 풀로는 1게임 후 식상함 — 카테고리는 콘텐츠 깊이 핵심
- **추정 코드**: CSV 카테고리 컬럼 + 메뉴 화면 → ~150 LOC + UI

### 🥉 P3. 100명 모드 (선택)
- **토글**: 50 ↔ 100 모드 전환 + arena 비율/sprite 크기 자동 조정
- **동기**: 영상 원본은 100을 메인, 50을 라이트 모드로 운영
- **추정 코드**: ALIVE_INITIAL 동적 + sprite 크기 clamp 조정 → ~50 LOC

### 시각 톤 보강 (소규모)

| 후보 | 추정 LOC | 효과 |
|---|---:|---|
| 캐릭터 세로 일렬 배치 (러닝 줄) | ~40 | 영상 톤 일치 |
| HUD 단순화 (그룹 시각 우선) | ~20 | 화면 깔끔함 |
| "나" 말풍선 노란 캡슐 | ~10 (CSS) | 플레이어 식별성 ↑ |
| 점수 ⭐ 아이콘화 | ~10 | 시각 임팩트 ↑ |

## 5. 미해결 / 추가 분석 권고 (v3 Plan 단계)

다음 항목은 본 분석으로 명확하지 않아 v3 Plan 진입 시 추가 프레임 캡처 권장:

1. **zone 분할 시각화** — OX 선택 직후 프레임 (우리 v2의 좌청록/우빨강 vs 원본 비교)
2. **탈락 이펙트 종류** — 4종 이펙트가 원본에서 어떻게 표현되는지 확인
3. **종료 화면 디자인** — win/lose 화면의 색감·코인 비·공유 동선
4. **Grand Slam 시각 보상** — 11라운드 도달 시 특별 화면 캡처
5. **NPC 메번직 모션** — NPC가 좌우 흔들리는 시각이 영상에선 어떻게 보이는지

> 추가 분석 비용: 영상 1개당 ~5초 × 5-10 프레임 = ~30-50 추가 캡처 → 약 5분.

## 6. 결론 (3줄)

1. **우리 v2는 원본의 핵심 메커니즘(50인 서바이벌·무한 라운드·4종 이펙트·러닝 BG)을 구조적으로 잘 따라함** — Match Rate 94.8% 외에도 컨셉 alignment 양호.
2. **결정적 차이는 "콘텐츠 깊이"** — 원본은 카테고리·레벨·Grand Slam·가상화폐 시스템으로 재플레이 동기 형성, 우리 v2는 단일 게임 루프만 존재.
3. **v3 ROI 1순위는 Grand Slam (11라운드 트리거 + 종료 화면 4분기 + 공유 문구)** — 코드 ~30 LOC로 콘텐츠 깊이 체감 강하게 ↑. 그 다음이 카테고리(P2), 100명 모드(P3) 순.
