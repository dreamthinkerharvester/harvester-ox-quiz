## 1. Executive Summary

| 관점 | 한 줄 요약 |
|------|-----------|
| **Problem** | 5년 동안 모은 OX 게임 비전은 거대해졌지만(마일리지·UGC·멀티플레이) 정작 **시장에 던져 반응을 본 적 없음** — 가설을 검증할 가장 작은 단위가 시급함. 동시에 이미 운영 중인 유튜브숏츠/틱톡/릴스 OX 콘텐츠가 **랜딩지점 없이** 자취생 네이버카페로만 흘러가 funnel이 새고 있음. |
| **Solution** | 퀴즈스틱맨의 **시각적 군중심리 연출**을 단순화한 정적 1페이지 웹게임으로 200문항 넌센스 OX 퀴즈를 제공. SNS 콘텐츠 → 웹게임 → (장래) 자취생카페·회원가입 funnel의 **첫 번째 종착지**를 만든다. 데이터·계정·마일리지 없는 의도적 미니멀. |
| **Function & UX** | 큰 둥근 O(청록)/X(빨강) 버튼 + Q.번호 + 라이프 3 + 정답시 반대편 캐릭터(이모지/SVG) 추락 + 종료시 "내가 짱!" 노란 폭발 화면. 200문항 풀(pool)에서 라운드당 무작위 N문항 출제. 모바일 세로 우선. |
| **Core Value** | 사용자에게: "1분만 풀어도 즐거운 만화풍 OX 게임". 사업적: **(a)** SNS funnel의 종착 랜딩 확보, **(b)** 5년 비전을 검증 가능한 작은 단위로 잘라낸 첫 출시, **(c)** 카테고리 확장(자격증·고시) 전 디자인·메커니즘 검증. |

## 2. Context Anchor

| 키 | 내용 |
|---|---|
| **WHY** | 5년 누적 OX 비전(2021~2025)의 **시장검증 진입점**. 동시에 이미 가동 중인 유튜브숏츠·틱톡·릴스 콘텐츠 funnel의 **랜딩 종착지** 부재 해결. |
| **WHO** | 1차: SNS에서 OX 콘텐츠 보고 흘러들어온 캐주얼 사용자 (자취생·20대 전반). 2차(검증 후): 자격증 준비생. 3차(장기): 대학 교수·학생 (CertiBattle Pro). |
| **RISK** | (1) 퀴즈스틱맨 디자인 자산 직접 복제 시 저작권. (2) 200문항 자체제작 품질이 균일하지 않으면 첫인상 훼손. (3) MVP가 너무 단순해 SNS funnel에서 와도 **재방문 이유 없음**. (4) 정적 사이트라 분석 데이터 수집이 매우 제한적. |
| **SUCCESS** | 출시 후 4주 내 — (a) 평균 세션 ≥ 3분, (b) 게임 완주율(시작→내가 짱!) ≥ 40%, (c) 친구 공유/링크 공유 발생 ≥ 50건, (d) SNS→웹 유입 트래킹 가능 (UTM). |
| **SCOPE** | **포함**: 200문항 OX 퀴즈, 라이프 3, Q.번호, 정답·오답 즉시 피드백, 종료 화면, 모바일 세로 반응형, 정적 호스팅(GitHub Pages). **불포함**: 회원가입, 로그인, 마일리지, 카테고리 선택 UI, UGC 제출, 멀티플레이, 랭킹, 백엔드 DB, 결제, 다국어. |

## 3. Beachhead Segment (Geoffrey Moore) + 단계적 시장 확장

### 3.1 Beachhead 정의 — "1차 MVP는 누구의, 무슨 1분을 채우는가?"

**선정 Beachhead**: **"이미 OX 콘텐츠를 SNS에서 본 자취생·20대 캐주얼 사용자"**

#### 4-criteria 평가

| 기준 | 점수 (1-5) | 근거 |
|---|---|---|
| **Reachable** | 5 | 이미 운영 중인 유튜브숏츠·틱톡·릴스 채널이 **곧바로 트래픽 소스**. 신규 채널 확보 비용 0. |
| **Pain Intensity** | 2 | 통증이라기보다 "시간때우기 도파민" — 강한 통증은 아니지만 진입 장벽도 매우 낮음. |
| **Easy to Win (경쟁 차별)** | 4 | 일반 OX 앱은 많지만 "퀴즈스틱맨식 시각 군중심리" + "넌센스 카테고리 큐레이션" 조합은 **웹에 없음**. |
| **Whole Product Fit** | 5 | 전체 솔루션(콘텐츠+게임)이 이미 파편 형태로 존재 — 게임만 만들면 합류 완성. |
| **합계** | **16/20** | Beachhead 적합. |

### 3.2 단계적 시장 확장 (Bowling Pin)

```
Pin 1 (1차 MVP, 본 PRD)        SNS 시청자 → 넌센스 OX 웹게임
   ↓ (검증: 완주율·공유율)
Pin 2 (3-6개월 후)             자취생 네이버카페·생활상식 카테고리 추가
   ↓ (검증: 카페 회원 유입·재방문)
Pin 3 (6-12개월)               공인중개사 OX (이미 콘텐츠 있음·랜드퀴즈 벤치)
   ↓ (검증: 자격증 시장 진입)
Pin 4 (12-18개월)              자격증 카테고리 N개 + 회원가입·마일리지 도입
   ↓ (Next.js 마이그·DB)
Pin 5 (18-24개월)              UGC 문제 제출·강사 참여·CertiBattle Pro 본체
```

**Pin 1 → Pin 2 진입 trigger**: 4주 누적 세션 5,000+ AND 평균 완주율 ≥ 40% AND 공유 ≥ 50건. 미달성 시 디자인·문제 품질 iteration 후 재검증.

## 4. Personas (3명) — 1차 타겟 1명 강조

### Persona 1 (1차 타겟·강조) — "지하철 위 시간때우기 자취생, 박지원 (24세)"

| 속성 | 값 |
|---|---|
| 인구통계 | 24세, 여성, 자취 1년차, 1.5룸 거주, 월 110만 원 비용 |
| 행동 | 출퇴근 30분 + 잠들기 전 1시간 = **하루 2회·1.5시간 짧은 SNS 콘텐츠 소비**. 인스타 릴스 → 유튜브숏츠 → 틱톡 순회 |
| JTBD | "**지루한 5분을 도파민 짧게 채우고 친구한테 공유할 거리**가 필요하다" |
| Pain | 인스타 릴스 다 봤음·알고리즘 식상함. 게임 앱 깔기는 귀찮음(저장공간·로그인 거부감). |
| Gain | "1분 만에 해본 거 친구한테 카톡으로 던지기". 정답 맞히면 잠깐의 우월감. |
| 채널 | 인스타·틱톡·유튜브숏츠 → 링크 클릭 → 모바일 웹 (앱 설치 거부) |
| Anti-pattern | 가입 요구·푸시알림·결제 화면 노출 시 즉시 이탈 |

## 7. Success Criteria — 1차 MVP 측정 가능 지표

| # | 지표 | 측정 방법 | 목표 (4주 출시 후) | 우선순위 |
|---|------|----------|-------------------|---------|
| **SC1** | **세션당 평균 플레이 시간** | GA4 또는 Plausible 이벤트 (`game_start` ~ `game_end`) | ≥ 3분 (= 약 30문항 이상) | 필수 |
| **SC2** | **게임 완주율** | (`game_end` 이벤트) / (`game_start` 이벤트) | ≥ 40% | 필수 |
| **SC3** | **공유·재방문 흔적** | 공유 버튼 클릭 이벤트 + Direct/Referral 트래픽 | 50건 이상 | 필수 |
| **SC4** | **SNS funnel 유입 트래킹** | UTM 파라미터별 분리 (utm_source=youtube_shorts/tiktok/instagram) | 3개 채널 모두 트래픽 ≥ 100세션 | 권장 |
| **SC5** | **모바일 세로 사용성** | 모바일 트래픽 비율 | ≥ 70% (주요 채널이 모바일이므로) | 권장 |

> 분석 도구: 정적 사이트 호환 — **Plausible (무료 OS 자체호스팅 가능) 또는 GA4** 권장. 1차에는 GA4 측정ID만 박아두는 가장 가벼운 형태.

### 명확한 비목표 (Non-Goals)

- 회원가입·로그인·DB·마일리지·UGC·멀티플레이·랭킹·결제·푸시알림·다국어 — **모두 1차 비포함**.
- 절대 평가 점수 (예: "100점 만점") 강조하지 말 것 — 학습 부담을 주지 않는 캐주얼 톤 유지.

## 8. Roadmap — 1차 → 2차 → 장기 (Phase 진입 trigger 명시)

### Phase 1 — 1차 MVP (이번 PDCA 사이클, ~4주)

**Scope**: 본 PRD §2 SCOPE 항목.
**기술**: 정적 HTML/CSS/JS 1페이지, GitHub Pages 무료 배포.
**데이터**: `data/questions_v1.csv` (200문항·자체제작 완료).
**진입 trigger**: 즉시 (이번 사이클).
**종료 trigger**: SC1·SC2·SC3 모두 달성 OR 출시 4주 경과.

### Phase 2A — 카테고리 확장 (3~6개월)

**Scope**: 카테고리 선택 UI 추가, "공인중개사" + "생활상식 자취생" 카테고리 신설. 라운드당 카테고리 선택. 여전히 정적 + JSON 데이터.
**진입 trigger**:
- Phase 1에서 SC1·SC2·SC3 모두 달성
- AND 사용자 피드백에서 "카테고리가 더 있으면" 명시적 요청 ≥ 10건
**종료 trigger**: 카테고리별 누적 세션 ≥ 1,000 이상 달성.

### Phase 2B — 동적화 + 회원/마일리지 (6~12개월)

**Scope**: Next.js 마이그레이션, Supabase/Firebase 백엔드, 회원가입·OTP 인증·**마일리지 경제(2025-08-22 정책회의 결정사항 그대로)** 적용.
**진입 trigger**:
- Phase 2A 종료조건 달성
- AND 자격증 카테고리 사용자 ≥ 500명 누적
- AND 자취생 네이버카페와 회원 데이터 통합 의사결정 완료
**종료 trigger**: 마일리지 인플레/디플레 균형 시뮬레이션 검증.

### Phase 3 — UGC + 강사 참여 + CertiBattle Pro 본체 (12~24개월)

**Scope**:
- Wikipedia식 UGC 문제 제출·검토 (2025-08-22 OX고도화 아이디어)
- 강사 참여형 답변 영상 (2023-05-30 raw 아이디어 + 2025 신규직렬 어젠다 ※ "강사 배제" 충돌 의사결정 선행 필요)
- CertiBattle Pro 본체: 대학 교수·학생 RBAC + 멀티플레이 + 4가지 방 초대 방식 중 Direct In-App Invitation
**진입 trigger**: Phase 2B 종료 + B2B 대학 1곳 이상 도입 의사 확인.

### Phase 4 — 실시간 멀티플레이 + 인앱결제 (24개월~)

**Scope**: WebSocket 기반 실시간 1:1 / 4인 대전 (2023-04-20 "1:1 모드 냄비뿅망치게임" 컨셉), 인앱결제 (2025-08-22 정책회의 "추후 논의" 항목).
**진입 trigger**: Phase 3 본격 운영 + 동시접속 평균 ≥ 50명.

### 의사결정 충돌 해소 필요 사항 (Phase 2B 진입 전 필수)

> **강사 참여 vs 강사 배제 충돌** (README §5)
> - 2023-05-30 메모: "강사 OX 풀이 영상" UGC 차별화
> - 2025-08-22 정책회의: "1단과 → 2강사 **배제**"
> - 2025-08-22 신규직렬준비: "강사참여(OX/랠리)" 재등장
> 1차 MVP scope 밖이지만 **Phase 2B(회원/마일리지) 진입 전 의사결정 필수**.

## 9. 차별화 핵심 — "시각적 군중심리 연출"

퀴즈스틱맨의 시그니처 메커니즘을 1차 MVP에서 **단순화된 형태로 반드시 구현**해야 다른 OX 게임 대비 차별점 확보:

| 요소 | 퀴즈스틱맨 원본 | 1차 MVP 단순화 |
|---|---|---|
| 분할 화면 | 좌(O 영역, 풀밭) / 우(X 영역, 동굴) | 좌(연한 청록, 5-7개 이모지) / 우(연한 빨강, 5-7개 이모지) |
| 캐릭터 | 30+종 라운드 chibi | **단순 이모지 (😀🤔😎🥳 등 5종 풀)** 또는 작은 SVG 1종 |
| 정답 시 | 반대편 캐릭터 추락 + 자기편 만세 | 반대편 이모지 CSS `transform: translateY(100vh)` 0.5s 애니 + 자기편 `bounce` 키프레임 |
| 오답 시 | 자기편 추락 + 라이프 -1 | 자기 이모지 흔들림 + 라이프 하트 ❤️→💔 |
| 승리 시 | 노란 폭발 + "내가 짱!" | CSS radial-gradient 노랑 + 큰 텍스트 "내가 짱!" |

> **법적 주의**: 퀴즈스틱맨 그래픽 자산(스티커맨 일러스트·UI 컴포넌트) 직접 복제 금지. **컬러 토큰·메커니즘 컨셉만 차용**, 모든 시각 자산은 자체 제작 또는 오픈소스(이모지·Google Fonts)만 사용.

## 10. SNS Funnel 연결 설계

```
[유튜브숏츠 OX 1문제] ─┐
[틱톡 OX 1문제] ──────┼──→ 영상 마지막에 "더 풀어보기 → 링크" CTA
[인스타 릴스 OX 1문제] ┘                  ↓
                                    [본 웹게임 / utm_source 추적]
                                          ↓
                                    [200문항 풀이 + "내가 짱!" 화면]
                                          ↓
                              [공유 버튼 → 카톡/링크 복사]
                                          ↓
                          (2차) [자취생 네이버카페 가입 CTA]
```

### 1차 MVP 연결 행동 (코드 구현)
- 모든 채널 링크에 **UTM 파라미터** 자동 부착 가이드 (운영팀에 별도 문서 제공)
- 종료 화면에 **"공유하기"** 버튼 1개 (Web Share API + 카톡 링크 복사 fallback)
- 종료 화면에 **"같은 거 또 풀기"** 버튼 1개 (재시작)
- (선택) 종료 화면에 **"자취생 네이버카페 보러가기"** 외부 링크 — A/B 테스트 가능

## 11. Risks & Mitigations

| Risk | Impact | Likelihood | Mitigation |
|------|--------|-----------|------------|
| 200문항 자체제작 품질 불균질 | 높음 | 중 | 출시 전 5명에게 50문항 샘플 풀이 시켜 명확한 오류·애매한 답 식별 후 수정 |

| 모바일 세로 화면 비율 문제 | 중 | 중 | 1차에서 9:16 모바일만 공식지원 명시. 데스크톱은 best-effort. |
