# PRD — 시험 OX 학습 파이프라인 (`exam-ox-pipeline`)

> **메타정보**
> - Feature slug: `exam-ox-pipeline`
> - 작성일: 2026-05-13
> - 작성: bkit:pm-lead Agent (PM Agent Team 4-agent 합성: pm-discovery + pm-strategy + pm-research + pm-prd)
> - 상태: Phase=PM 완료, 다음=`/pdca plan exam-ox-pipeline`
> - 단기 목표: 세무사·회계사 **경제학·재정학** 기출 PDF → 메타데이터 보강 OX DB → 학습 페이지 (문항+해설+영상+범위 표기)
> - 장기 비전: 자격증·공무원 시험 OX 학습 통합 플랫폼. 5년 누적 OX 비전(마일리지·UGC·강사 참여·신규직렬) 중 "**문제DB+학습도구**" 트랙의 실체화
> - 관계: 기존 `nonsense-quiz-mvp`(완료, SNS funnel용 캐주얼 게임)와는 **별도 도메인의 자매 사이트**. 같은 인프라/디자인 토큰 일부 재사용. v4 카테고리 시스템(survival-mode-v3 후속)이 본 PRD에 흡수되어 본격 전개.

## 1. Executive Summary

| 관점 | 한 줄 요약 |
|------|-----------|
| **Problem** | 수험생은 OX 문제를 풀다가 모르는 부분이 나오면 (1) 책을 다시 펴거나 (2) 유튜브 검색하거나 (3) 챗GPT에 묻거나 (4) 그냥 넘어간다. **풀이→학습 이동 비용**이 매우 높아 OX의 "빠른 반복" 강점이 무력화된다. 동시에 1,700+ PDF로 이미 확보 중인 기출자료는 **단순 OX 변환** 단계에 머물러 있고, **출제범위·관련이론·관련영상** 같은 학습 메타데이터가 비어 있어 단순 문제풀이 도구에 그친다. |
| **Solution** | 기존 `scripts/build_quiz_db.py`의 Type A/B/C 변환 로직을 코어로 유지하고, 그 위에 **메타데이터 추출 레이어** + **해설 보강 레이어** + **학습 페이지 레이어** 3층을 얹는다. 한 문항을 풀면 즉시 "왜 O/X" 해설, 출제범위(예: 재정학 §3 외부효과), 관련 이론(예: 코즈 정리), 관련 영상(YouTube), 교과과정 중 학습할 부분이 같은 화면에 노출된다. |
| **Function & UX** | (1) 풀이 모드: 문항 → O/X 선택 → 즉시 결과 + 짧은 해설 + "더 학습하기" 토글. (2) 더 학습하기 펼침: 출제범위 / 태그 / 관련 이론 / 관련 유튜브 영상 1~3개 / 교과서 챕터. (3) 카테고리 선택: 자격증 > 시험 회차 > 과목 트리. (4) 학습 진척: 과목별 완료율·오답노트. **모바일 세로 우선**, 데스크톱 best-effort. |
| **Core Value** | 사용자에게: "OX 한 문제 풀면 학습 흐름이 끊기지 않는다." 사업적: **(a)** 세무사 경제학·재정학 Beachhead 진입 → 회계사·자격증·공무원으로 Bowling Pin 확장, **(b)** 1,700+ PDF 크롤링 자산을 학습 자산으로 활성화, **(c)** 5년 비전의 "마일리지 경제·UGC·강사 참여" 트랙이 결합될 **본격 학습 사이트의 골격**. |

## 2. Context Anchor

| 키 | 내용 |
|---|---|
| **WHY** | 1,700+ PDF(최종 50,000+ 예상)와 검증 완료된 OX 변환 파이프라인이 이미 있다. 누락된 건 "**풀이→학습 이동 비용 0**"을 만드는 학습 메타데이터 + UI. 동시에 5년 비전의 "문제DB 트랙"을 가장 빠르게 실체화하는 경로. |
| **WHO** | 1차(Beachhead): **세무사 1차 수험생 중 경제학·재정학 과목 약점자**. 2차: 회계사 1차 수험생(경제학·경영학). 3차: 9급/7급 공무원 시험 한국사·헌법 수험생. **모바일 자투리 시간(출퇴근·점심·취침전) 학습자**가 공통 핵심. |
| **RISK** | (1) 자동 메타데이터 추출 품질이 낮으면 학습 페이지가 "그럴듯한 거짓말"로 채워져 신뢰 추락. (2) LLM 해설 자동 생성 시 환각 위험 — 회계·재정학은 정답 근거가 명확해야 함. (3) YouTube 영상 자동 매칭은 채널 폐쇄·내용 불일치 위험. (4) 1,700 PDF 중 일부는 OCR이 아닌 깨진 텍스트 → 변환 실패. (5) 하베스터 PDF 저작권 — 학습 목적 fair use 가정이나 명시 필요. |
| **SUCCESS** | 출시 후 6주 내 — (a) 세무사 경제학·재정학 OX 누적 ≥ 1,500문항(메타 채워진 것 기준), (b) 문항당 평균 메타 완성도 ≥ 80% (출제범위·태그·해설 모두 채워진 비율), (c) "더 학습하기" 클릭율 ≥ 35%, (d) 세무사 수험생 카페·블로그 inbound 트래픽 ≥ 500세션. |
| **SCOPE** | **포함**: 기존 `scripts/build_quiz_db.py` 코어 유지·확장, 메타데이터 추출(rule+LLM 하이브리드), 해설 보강(rule+LLM), 학습 페이지 1개(문항+해설+영상+범위+학습포인트), 카테고리 트리(자격증>시험회차>과목), 오답노트, 모바일 세로 반응형. **불포함**: 회원가입/로그인/마일리지/결제(Phase 2+), UGC 문항 제출(Phase 3+), 멀티플레이·서바이벌(별도 `nonsense-quiz-mvp` 라인), 강사 참여 영상(의사결정 충돌 미해소·Phase 3 이후). |

## 3. Beachhead Segment (Geoffrey Moore) + 단계적 시장 확장

### 3.1 Beachhead 정의 — "왜 세무사 경제학·재정학인가?"

**선정 Beachhead**: **세무사 1차 수험생 중 경제학·재정학 과목 학습자** (사용자 명시)

#### 4-criteria 평가

| 기준 | 점수 (1-5) | 근거 |
|---|---|---|
| **Reachable** | 4 | 세무사 카페(다음·네이버)·합격수기 블로그·웅지·나무·우리 학원 채널 명확. 인터넷강의 학원 의존도 매우 높아 검색 행동 일관. |
| **Pain Intensity** | 5 | 세무사 1차 합격률 약 15-25% / 재정학·경제학은 평균 점수 분포가 가장 낮은 과목. **"이해 안 되는데 그냥 풀고 넘긴" 부담**이 매우 강함. OX로 빠르게 약점 진단 + 즉시 학습 연결 통증이 정확히 매칭. |
| **Easy to Win (경쟁 차별)** | 4 | 랜드퀴즈 류는 공인중개사 중심·UI 낙후. 학원 OX는 폐쇄형 LMS. "기출 자동 OX 변환 + 학습 메타 + 영상 연결"을 모바일에서 통합 제공하는 곳 없음. |
| **Whole Product Fit** | 5 | (a) 이미 build_quiz_db.py로 144문항 OX 검증 완료, (b) 1,700+ PDF 확보 중, (c) 유튜브 영상 매칭은 공개 검색으로 충당 가능 — **전체 솔루션 즉시 조립 가능**. |
| **합계** | **18/20** | Beachhead 매우 적합. |

#### 왜 "경제학·재정학"을 첫 번째 칸으로 잡았나?

| 이유 | 설명 |
|---|---|
| **타과목 대비 OX 적합도 최고** | 회계학(계산), 세법(조문 인용), 상법·민법(판례)에 비해 경제학·재정학은 **개념·이론 진술이 OX로 가장 자연스럽게 분해됨**. 기존 144문항 변환 성공률이 이를 입증. |
| **학습 메타 추출이 가장 깔끔** | 경제학 키워드(외부효과·코즈정리·파레토최적)는 사전 매핑 가능. 회계 계산식·세법 조항은 별도 작업 필요. |
| **YouTube 콘텐츠 풍부** | "재정학 외부효과" 검색 시 박지홍·웅지·이00 등 무료 강의 풍부. 회계 계산보다 영상 매칭 신뢰도 높음. |
| **확장 경로 명확** | 경제학 → 행정고시·CPA·노무사·관세사·감정평가사 모두 **동일 도메인** 사용. Beachhead 1곳에서 6개 자격증으로 자연 확장. |

### 3.2 단계적 시장 확장 (Bowling Pin)

```
Pin 1 (1차 MVP, ~6주)             세무사 1차 경제학·재정학 OX + 학습 메타
   ↓ (검증: 학습 메타 완성도 ≥80% + 문항 ≥1,500개 + 더 학습 클릭율 ≥35%)

Pin 2 (3개월)                     세무사 1차 전과목 확대 (세법·회계·상법·민법·행정소송법)
   ↓ (검증: 과목별 누적 풀이 ≥10,000회 + 오답노트 활성 사용자 ≥100명)

Pin 3 (6개월)                     회계사 1차 (경제학·경영학·회계학·세법) — 경제학 도메인 그대로 재사용
   ↓

Pin 4 (9개월)                     공무원 9급 한국사 + 헌법 — 텍스트 진술 OX 적합
   ↓

Pin 5 (12개월)                    회원가입·마일리지·오답노트 동기화 (2025-08-22 정책회의 시스템 적용)
   ↓

Pin 6 (18개월)                    UGC (사용자 직접 OX 제출), 강사 참여 영상 검토 (의사결정 충돌 해소 후)
```

**Pin 1 → Pin 2 진입 trigger**: SC1·SC2·SC3 모두 달성 (§7 참조) AND 세무사 카페 1곳 이상에서 자발적 언급 발생.

## 4. Personas (3명) — 1차 타겟 1명 강조

### Persona 1 (1차 Beachhead 핵심) — "세무사 2년차 수험생, 정현우 (28세)"

| 속성 | 값 |
|---|---|
| 인구통계 | 28세, 남성, 전 직장 회계법인 1년차 퇴사 후 세무사 준비 2년차 (1차 1회 낙방) |
| 일과 | 독서실 09:00–22:00, **출퇴근 지하철 50분 + 점심 30분 + 취침전 30분 = 자투리 110분/일** 모바일 학습 가능 |
| JTBD | "**경제학·재정학 약한 단원을 출퇴근 지하철에서 OX로 빠르게 진단하고, 모르는 건 그 자리에서 30초 안에 학습**하고 싶다" |
| Pain | (1) 책 펴기는 자리·시간 부담, (2) 학원 LMS는 모바일 UX 답답, (3) 챗GPT는 정답 신뢰 의심, (4) 단순 OX 앱은 해설 없거나 "X" 한 글자뿐, (5) 유튜브 검색은 영상 길어서 30초 안 됨 |
| Gain | 한 화면에 — 문항 + 즉시 OX + 짧은 해설(왜 X) + 출제범위 표시("재정학 §3 외부효과") + 관련 영상 1~3개 + 책 챕터 — 모두 노출 |
| 채널 | 다음세무사카페, 네이버 세무사 학원카페, 웅지·나무 학원 후기 블로그, 유튜브 박지홍 |
| Anti-pattern | 회원가입 요구 / 결제 화면 노출 / 광고 과다 / 해설이 "X" 한 글자 / 로딩 3초+ |
| Top Quote | "재정학은 이론이 외워지지 않는데, 책 펴면 1시간이라 망설여진다. 그렇다고 강의 다시 듣자니 시간 낭비." |

> **이 페르소나가 1차 MVP 핵심 검증 대상**. 정현우가 지하철에서 한 손으로 — 5초 만에 카테고리 진입, 30초 만에 1문항 풀이+학습, 1분에 2~3문항 회전 가능해야 함.

## 8. Roadmap — 1차 → 2차 → 장기 (Phase 진입 trigger 명시)

### Phase 1 — 1차 MVP (이번 PDCA 사이클, ~6주)

**Scope**:
- 기존 `scripts/build_quiz_db.py` 확장 (메타 추출 함수 추가)
- 메타 추출 레이어: 키워드 사전(경제학 핵심 100개) + LLM fallback
- 해설 보강 레이어: PDF 해설 추출 → 없으면 LLM "왜 O/X" 코멘트 (≤80자)
- 학습 페이지 1개 (모바일 세로): 문항 → 답 → 해설 → 더 학습하기(범위·태그·영상·이론)
- 카테고리 트리: 세무사 1차 > 2026년 제63회 > 경제학·재정학 (확장 가능 구조)
- 오답노트 (LocalStorage 기반, 회원 X)
- YouTube 영상 매칭 (수동 큐레이션 + 검색 API 자동 추천, 사용자 승인 후 DB 적재)

**기술**:
- 백엔드: Python 스크립트(build_quiz_db.py 계열) + SQLite (data/quiz.db 확장)
- 프런트: 정적 HTML/CSS/JS (또는 Astro/Next.js static export 검토 — Plan 단계 결정)
- 호스팅: GitHub Pages 또는 Cloudflare Pages 무료
- LLM: Claude Sonnet/Opus API (메타 추출·해설 fallback), 비용 가드 적용

**데이터**: 세무사 1차 2026년 제63회 경제학·재정학 + 2025·2024·2023 회차 추가 (≥3개 회차)

**진입 trigger**: 즉시
**종료 trigger**: SC1·SC2·SC3 모두 달성 OR 출시 6주 경과

### Phase 2 — 세무사 1차 전과목 확장 (3개월)

**진입 trigger**: Phase 1 종료 + 사용자 피드백에서 "타과목" 명시 요청 ≥ 5건

### Phase 3 — 회계사·인접 자격증 (6개월)

**Scope**: 회계사 1차(경제학·경영학·회계학·세법) 추가. 경제학 도메인은 세무사와 통합. 노무사·관세사·감정평가사 인접 도메인 점진.

## 9. 차별화 핵심 — "풀이와 학습 사이의 0클릭"

본 PRD의 단일 차별점:

```
일반 OX 앱:    [문항] → [O/X] → [정답: X. 끝]                  (학습 끊김)
일반 학습 앱:  [강의 1시간] → [필기 30분] → [문제 풀이]         (시간 부담)
구글링:        [검색] → [10개 링크 검토] → [그 중 1개 클릭]     (산만)
ChatGPT:       [질문] → [답 신뢰 의심] → [재검증]               (피로)

우리:         [문항] → [O/X] → [정답 + 짧은 해설]               (5초)
                                  ↓ 더 학습하기 (선택 펼침)
                              [출제범위 §3 외부효과]
                              [태그: 코즈정리, 외부비용]
                              [관련 영상 1~3개 (YouTube)]
                              [교과서 챕터 표시]              (30초)
                                  ↓
                              [다음 문항]
```

### 학습 페이지 컴포넌트 (1차 MVP)

| 영역 | 내용 | 데이터 출처 |
|---|---|---|
| **A. 문항** | 진술 텍스트 | `questions.statement` |
| **B. 답 + 짧은 해설** | "X" + "재산세·증여세는 인세(in personam tax)에 해당" (≤80자) | `questions.explanation` (PDF 우선, LLM fallback) |
| **C. 출제범위** | "재정학 §3 외부효과 / 코즈정리" | LLM 분류 (경제학 단원 사전 매핑) |
| **D. 태그** | ["코즈정리", "외부효과", "거래비용"] | LLM 추출 + 키워드 사전 검증 |
| **E. 관련 이론** | "코즈정리(Coase Theorem) — 거래비용이 0이면 권리 배분에 관계없이 효율적 자원 배분" | LLM 생성 (≤120자) |
| **F. 관련 영상** | YouTube 임베드 1~3개 (제목·길이) | 큐레이션 + YouTube Data API v3 (수동 승인) |
| **G. 교과 학습 포인트** | "기본서 박지홍 재정학 p.187 / 강의 6강 17:30~" | 수동 매핑 (관리자가 회차별 입력) |

> **품질 가드**: B(해설), E(이론)는 LLM 생성 시 `[자동 생성·검증 필요]` 마커. F(영상)는 사용자 승인 전 노출 X.

```
                              ↓ (신규 레이어)

│    - 키워드 사전 (재정학 100개 / 경제학 150개)                    │
│    - LLM 메타 보강 (출제범위·태그·관련이론)                       │
│    - 해설 fallback (PDF 미수록 시 LLM "왜 O/X" 코멘트)            │
└──────────────────────────────────────────────────────────────────┘
                              ↓
┌──────────────────────────────────────────────────────────────────┐
│ ⑤ DB 스키마 확장 (data/quiz.db v2)                                │
│    questions 테이블에 컬럼 추가:                                  │
│      - scope_path (출제범위)                                      │
│      - tags (JSON array)                                          │
│      - related_theory (이론 요약)                                 │
│      - related_videos (JSON array: [{url, title, sec}])           │
│      - textbook_ref (교과서 챕터)                                 │
│      - meta_quality (수동/자동/혼합)                              │
└──────────────────────────────────────────────────────────────────┘
                              ↓ (export)
┌──────────────────────────────────────────────────────────────────┐
│ ⑥ 학습 페이지 (정적 HTML/CSS/JS)                                  │
│    - data/quiz/*.json 직접 fetch                                  │
│    - LocalStorage: 오답노트, 진척률                               │
└──────────────────────────────────────────────────────────────────┘
```

### DB 스키마 변경안 (요약)

```sql
ALTER TABLE questions ADD COLUMN scope_path TEXT;          -- "재정학 §3 외부효과"
ALTER TABLE questions ADD COLUMN tags TEXT;                -- JSON: ["코즈정리","외부효과"]
ALTER TABLE questions ADD COLUMN related_theory TEXT;      -- "코즈정리(Coase Theorem) — ..."
ALTER TABLE questions ADD COLUMN related_videos TEXT;      -- JSON: [{url,title,sec}]
ALTER TABLE questions ADD COLUMN textbook_ref TEXT;        -- "박지홍 재정학 p.187"
ALTER TABLE questions ADD COLUMN meta_quality TEXT;        -- 'auto'|'manual'|'mixed'|'pending'
ALTER TABLE questions ADD COLUMN meta_updated_at TEXT;

CREATE TABLE IF NOT EXISTS keywords (
    id INTEGER PRIMARY KEY,
    subject TEXT NOT NULL,         -- '재정학','경제학',...
    keyword TEXT NOT NULL,         -- '코즈정리'
    scope_path TEXT,               -- '재정학 §3 외부효과'
    aliases TEXT,                  -- JSON: ['Coase','거래비용']
    UNIQUE(subject, keyword)
);

CREATE TABLE IF NOT EXISTS video_curation (
    id INTEGER PRIMARY KEY,
    keyword_id INTEGER REFERENCES keywords(id),
    url TEXT NOT NULL,
    title TEXT,
    duration_sec INTEGER,
    approved_at TEXT,              -- NULL이면 미승인 (UI 노출 X)
    notes TEXT
);
```

> Plan 단계에서 schema migration 전략 결정 (v1 보존 vs in-place ALTER).

## 11. Risks & Mitigations

| Risk | Impact | Likelihood | Mitigation |
|------|--------|-----------|------------|
| **LLM 메타 추출 환각** | 매우 높음 | 중 | (1) 키워드 사전 우선 → LLM은 fallback, (2) 자동 생성분에 `[자동·검증 필요]` 마커, (3) 100문항당 10% 무작위 샘플 수동 검수 |
| **LLM API 비용 폭주** | 높음 | 낮음 | 전역 비용 가드(`/tmp/api-cost-breach.lock`) 적용. 1회 batch 처리 후 캐싱. |
| **PDF 일부 깨진 텍스트** | 중 | 높음 | 변환 실패 row는 `meta_quality='pending'`으로 표시. OCR fallback은 Phase 2 이후. |
| **YouTube 영상 폐쇄·내용 불일치** | 중 | 중 | 매주 cron으로 video URL HEAD 체크 + 사용자 신고 버튼 |
| **하베스터 PDF 저작권** | 높음 | 낮음 | (1) 학습 목적 fair use 명시, (2) 원본 PDF 재배포 X (텍스트 진술만 재구성), (3) "출처: 하베스터" 명시, (4) 영구 OFF 요청 시 즉시 삭제 정책 |
| **메타 추출 70% 자동화 미달** | 높음 | 중 | (1) Plan 단계에서 키워드 사전 100개 → 200개 보강 검토, (2) 자동화 미달 시 SC2 목표 80%→70% 하향 가능 |
| **자매 사이트(`nonsense-quiz-mvp`) 와 톤 충돌** | 중 | 중 | UX 분리: 본 사이트는 "학습 도구", `nonsense`는 "캐주얼 게임". 도메인 별도. 디자인 토큰 일부만 공유. |
| **세무사 카페 침투 실패** | 높음 | 중 | (1) GTM 단계에서 시드 콘텐츠 5건 사전 작성(블로그 후기·OX 50문항 무료), (2) 카페 운영자 사전 컨택 |

### Pre-mortem — "6주 후 실패했다면 원인은?"

| 가설 | 사전 차단책 |
|---|---|
| 메타 자동 추출 품질이 50% 이하 | Phase 1 첫 2주에 100문항 파일럿 + 수동 검증 → 사전 calibration |
| 학습 페이지가 모바일에서 답답 | Persona 1 정현우 가상 시나리오 wireframe Plan 단계 필수 |

| 1,500문항 미달 (메타 보강 시간 부족) | 회차 ≥3개 강제 + 메타 빈칸 허용(meta_quality='pending') |
