**해소 옵션**

- (B) Tesseract 한국어 OCR — 시험지 PDF → 페이지 이미지(`pdftoppm -r 300`) → `tesseract -l kor` → 정규식 파싱. 정확도 70~85% 예상
- (C) 다른 출처(법령정보센터·온라인 해설 사이트)에서 정답 재확보
