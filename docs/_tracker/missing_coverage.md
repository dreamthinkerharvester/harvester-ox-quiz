## 3. 2024년 이전 데이터 (별도 처리)

`build_generic_db.py --year YYYY` 옵션으로 옛 연도 추가 가능.
2009~2023 데이터도 같은 공기출 표준 양식이면 일괄 처리 가능.

---

## 4. 다음 확장 후보

1. **2020~2023 데이터 일괄** — 같은 빌더로 가능 (예상 +50,000 OX)
2. **이미지 PDF OCR** — Tesseract 한국어 (`brew install tesseract tesseract-lang`)
3. **시험지 추출 다양화** — pdftotext / pdfminer / Camelot 추가 fallback
4. **해설 파일명 패턴 확장** — "공기출" 외 강사명 해설(이형재·김재준·김동현·이승철 등)
